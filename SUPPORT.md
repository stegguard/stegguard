# Support

StegGuard is maintained by volunteers and does not include a guaranteed support
service or response time.

Use the repository issue forms for reproducible bugs, false positives, false
negatives, and feature requests. Use GitHub Discussions, when enabled, for
general questions. Before posting, check the README, current issues, and the
platform and compatibility documents in `docs/`.

Include the StegGuard version, Python version, operating system, command, exit
code, and a minimal safe input description. Redact secrets and personal data.
Do not post security vulnerabilities publicly. Follow [SECURITY.md](SECURITY.md)
instead.

StegGuard reports investigative signals. Project support cannot certify that a
file is safe, attribute authorship, provide incident-response services, or
replace a qualified security review.
